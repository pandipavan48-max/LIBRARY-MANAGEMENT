● Powered by Neo4j Graph Database

Book recommendations are generated using collaborative filtering on a property graph. Members who borrowed similar books are connected, and new recommendations are surfaced via Cypher queries.

🔎 Cypher Query (Live)
MATCH (u:Member {id: $memberId})-[:BORROWED]->(b:Book)
<-[:BORROWED]-(similar:Member)-[:BORROWED]->(rec:Book)
WHERE NOT (u)-[:BORROWED]->(rec)
RETURN rec.title, rec.author, COUNT(*) AS score
ORDER BY score DESC LIMIT 5
